============================================================
vue3-server 后端启动说明（Spring Boot 3.2 + Java 21 + MySQL + Redis）
============================================================

【⭐ 标准启动顺序（每次重启电脑都要按这个来）】
本机数据库没有注册成 Windows 服务，不会开机自启，所以每次重启后必须手动启动：
    第 1 步：双击 E:\start_databases.bat   → 启动 MySQL(3306) + Redis(6379)
    第 2 步：启动后端                      → mvnw.cmd spring-boot:run ...
    第 3 步：启动前端                      → npm run dev（5173）
提醒：只关数据库、不关后端/前端，接口会立刻连不上；正常停机请先停应用，再关数据库。

============================================================
一、数据库：手动启动与关闭（重点）
============================================================
▶ 启动：双击 E:\start_databases.bat
    - 以“进程方式”开两个最小化后台窗口（分别跑 MySQL / Redis）
    - 绑定你当前的登录会话，关机/注销前一直运行
    - 启动后验证：
        mysql -u root -proot123456 -e "SELECT 1;"
        redis-cli -h 127.0.0.1 -p 6379 ping      （返回 PONG 即正常）

▶ 关闭（三种方法任选其一）：
    方法 A：直接关闭对应的 MySQL / Redis 后台窗口
    方法 B：双击 E:\stop_databases.bat（若已提供该脚本）
    方法 C：任务管理器里结束 mysqld.exe / redis-server.exe 进程

说明：当前环境无管理员权限，未注册为服务，所以必须手动启动；
      重启电脑后数据库不会自动起来，需要重新双击 start_databases.bat。

============================================================
二、建库建表（首次运行，只需做一次）
============================================================
用管理员打开 cmd，执行：
    "E:\mysql\bin\mysql.exe" -u root -p < "F:\workBuddy\space\vue3-server\src\main\resources\sql\init.sql"
回车后输入你的 MySQL root 密码即可（脚本会建数据库 vue3_user + 表 user）。
脚本含 DROP TABLE IF EXISTS，可反复执行（会清空表）。

============================================================
三、修改数据库连接密码
============================================================
编辑文件：
    F:\workBuddy\space\vue3-server\src\main\resources\application.yml
把第 20 行附近的 password 改成你真实的 MySQL root 密码：
    password: 你的真实密码

============================================================
四、启动后端（前置：确保【一】数据库已启动）
============================================================
进入项目目录后执行：
    cd F:\workBuddy\space\vue3-server
    mvnw.cmd spring-boot:run -Dspring-boot.run.arguments="--server.port=8080"

⚠️ 为什么一定要带 --server.port=8080 ？
  本机存在一个环境变量 SERVER__PORT=0（宿主/IDE 注入），Spring Boot
  会把它解析成 server.port=0，优先级高于 application.yml 里的 8080，
  导致后端监听随机端口、前端(5173 代理到 8080)调不通。
  用上面的 -Dspring-boot.run.arguments="--server.port=8080" 强制压住即可。

  等价做法（二选一）：
    set SERVER__PORT=8080
    mvnw.cmd spring-boot:run

============================================================
五、验证启动成功
============================================================
看到以下两行日志即成功：
    Tomcat started on port 8080 (http) with context path ''
    Started UserServerApplication in X.XXX seconds

接口自检（浏览器或 curl）：
    http://localhost:8080/api/users
  正常返回：{"code":0,"message":"ok","data":{"records":[],"total":0}}

============================================================
六、前端（另一个项目 vue3）
============================================================
    cd F:\workBuddy\space\vue3
    npm run dev        # http://localhost:5173
  顶栏「新建用户」「用户管理」即可对 MySQL 做增删改查。

============================================================
八、通用说明
============================================================
- 后端自带 Maven Wrapper（mvnw.cmd），无需全局安装 Maven。
- 重启电脑后，数据库 / 后端 / 前端进程都会消失，需按顺序重来：【一】→【四】→【六】。
